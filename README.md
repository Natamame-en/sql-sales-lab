# sql-sales-lab

SQL/DBの実務能力向上を目的とした、販売データ分析アプリの学習プロジェクトです。

大量データ（注文100万行・注文明細300万行）を対象に、まず素朴な実装を作り、実行計画と計測を根拠に改善していく過程を記録します。

## 技術構成

- C# / ASP.NET Core（Razor Pages）
- EF Core ＋ Dapper
- PostgreSQL 16（Docker Compose）

## 画面

1. 月次売上レポート（ウィンドウ関数：前月比・累計）
2. 顧客別売上ランキング（CTE多段集計）
3. N+1比較画面（EF Core／JOIN／生SQLの3方式で発行クエリ数と実行時間を比較）
4. 重い検索画面（索引追加前後のベンチマーク）
5. 改善ログ（実行時間・実行計画のビフォーアフター）

## セットアップ

```bash
docker compose up -d
# db/schema.sql → db/seed.sql の順に実行
```

## 学習の進め方

1. 現在の知識で素朴に実装する（索引なし・N+1ありの状態をあえて作る）
2. 実行時間と実行計画を計測し、改善ログにビフォーを残す
3. 『SQL実践入門』『SQLパフォーマンス詳解』で得た知識で改善し、アフターを計測する
